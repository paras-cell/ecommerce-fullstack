┌─────────────────────────────────────────────────────────────────────────────┐
│                      🔐 SECURITY FEATURES                                   │
└─────────────────────────────────────────────────────────────────────────────┘

✅ PASSWORD SECURITY
   • Hashed with bcryptjs (10 salt rounds)
   • Never stored in plain text
   • Verified with comparison function
   • Strong password requirements enforced
   • Password strength indicator on registration

✅ EMAIL VERIFICATION
   • OTP sent to email before account creation
   • Valid for 5 minutes
   • Rate limited (1 OTP per minute)
   • Auto-deleted after expiry

✅ TOKEN SECURITY
   • JWT tokens signed with secret key
   • Access token valid 7 days
   • Refresh token valid 30 days
   • Tokens stored in localStorage
   • Bearer token in Authorization header

✅ PROTECTED ROUTES
   • Middleware verifies JWT
   • Unauthenticated access redirected
   • Tokens refreshed automatically
   • Failed verification returns 401

✅ BEST PRACTICES
   • Input validation everywhere
   • Error messages don't leak information
   • Passwords confirmed before changing
   • Old password verified before change
   • User status checked on login

PASSWORDS
  Requirements: 8+ chars, uppercase, lowercase, number
  Hashing: bcryptjs (10 salt rounds)
  Storage: Hashed only (never plain text)

TOKENS
  Access Token: Valid 7 days
  Refresh Token: Valid 30 days
  Storage: localStorage
  Format: JWT (JSON Web Token)

EMAIL
  Method: Nodemailer + Gmail SMTP
  OTP: 6 digits, valid 5 minutes
  Rate limit: 1 per minute

ROUTES

  Redirect: To /login if not authenticated
