## 🚀 HOW TO TEST

1. Start Backend:
   cd server
   npm start

2. Start Frontend:
   cd frontend
   npm run dev

3. Open Browser:
   http://localhost:5173

4. Test Login:
   - Go to /register
   - Complete registration (OTP + Password)
   - Verify name appears in navbar

5. Test Cart:
   - Go to any product page
   - Add item to cart
   - Verify "Bag (1)" appears in navbar

6. Test Wishlist:
   - Go to any product card
   - Click wishlist icon
   - Verify "Wishlist (1)" appears in navbar

7. Test Dropdown:
   - Click on user name in navbar
   - Verify dropdown appears with all 4 menu items
   - Click "Logout" to test logout
